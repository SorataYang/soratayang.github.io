# 16.1 自振特性**分析**

- 桥通软件支持采用集中质量矩阵或者一致质量矩阵进行自振特性分析，输出结构的频率、周期、振型参与质量、参与系数以及指定的振型模态。自振特性分析前，应完成建立结构整体模型、定义节点质量或将荷载转换为质量等必要步骤。自振特性分析的主要操作流程为：

  1\) 在“分析>自振”中指定进行自振分析，指定计算矩阵以及振型模态数量。

  2\) 点击“分析>运行分析”，或快捷键进行分析；

  3\) 分析成功后，通过“结果>周期与振型”查看指定设置分析的所有振型相关表格结果，通过“模态>振型”查看指定振型的模态位移图形结果。
- 自振特性分析设置详见：10.4 **自振设置**，结果输出详见：11.3 **自振及屈曲分析结果**。

# 16.2 **反应谱分析**

采用桥通软件进行反应谱分析步骤如下：

- 在“分析 >反应谱分析 ”中进行反应谱分析设置，详见 \*\*。注意，进行反应谱分析的前提是必须进行自振分析，因此应**确保执行自振分析**。

- 在“荷载 >动力荷载 反应谱函数”中添加、修改或删除反应谱函数，详见 \*\*。

- 在“荷载 >动力荷载 反应谱工况”中添加、修改或删除反应谱工况，详见 \*\*。

- 点击计算，完成后可在“结果 >反应谱分析”中查看反力、变形、梁杆索和组合梁单元内力应力、板单元内力应力等结果的表格和图形，详见 \*\*。

# 16.3 **动力时程分析**

- 桥通软件支持线性和边界非线性的动力时程分析，输出结构变形、内力和应力等动力响应。时程分析设置流程为：
  1. 在“荷载>动力荷载>时程荷载工况”中定义动力工况；
  2. 在“荷载>动力荷载>时程函数”中定义荷载随时间变化的时程函数；
  3. 若需要考虑边界非线性支承结构，则在“荷载>动力荷载>边界单元特性”中定义边界非线性单元特性值，再在“荷载>动力荷载>边界单元连接”中将边界非线性支承添加到结构中；
  4. 若进行地震分析，在“荷载>动力荷载>地面加速度”中设置地震荷载方向和系数；
  5. 若进行节点荷载分析，在“荷载>动力荷载>节点动力荷载”中设置节点动力荷载方向、到达时间以及系数。
  6. 在“分析>时程分析”中指定进行时程分析，选择输出的节点位移和内力结构组；
- 时程分析设置详见：10.8 **时程分析设置**，荷载设置详见：9.4 动力荷载，表格结果输出详见：11.2 **动力分析结果**。
