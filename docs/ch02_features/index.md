桥通软件包含的主要模块和功能如下（✮ 表示特色/增强功能）。

### 有限元计算模块

| 特色 | 功能 |
| :---: | --- |
|  | 单元库：梁单元、杆单元、索单元、壳单元 |
|  | 材料库：混凝土、钢、预应力、钢筋、自定义；支持正交异性材料 |
|  | 截面库：一般混凝土、钢桁梁、型钢截面、组合梁、钢箱梁、变截面 |
| ✮ | 数形双向驱动截面编辑器 |
|  | 边界：一般支承、弹性支撑、主从约束、弹性连接、约束方程、释放梁端、局部坐标系 |
|  | 荷载：风、温度、沉降、收缩徐变、制造偏差、预应力等 |
|  | 一般静力分析 / 自振与屈曲 / 反应谱分析 |
|  | 几何非线性：完全非线性、部分非线性 |
| ✮ | 非线性动力时程分析、边界非线性单元 |
|  | 荷载组合：叠加、包络、判别、平分及开方、绝对值之和等 |
|  | 后处理：反力、变形、内力、应力；并发反力/并发内力表格 |

| 特色 | 功能 |
| :---: | --- |
| ✮ | 箱梁横向建模助手 |
| ✮ | 悬浇梁建模助手 |
| ✮ | 斜拉索智能调索 |
|  | 悬索桥空间主缆找形 |
|  | 有效宽度计算 |
| ✮ | 参数化变截面 |
| ✮ | 无应力状态法：索力张拉、索长张拉 |
| ✮ | 制造偏差设置 |
|  | 施工阶段分析 |
| ✮ | 轨道形位分析 |
| ✮ | 钢栈桥、贝雷梁施工大临建模助手 |
|  | 移动荷载（影响面）：公路、铁路、市政、轨道活载及自定义 |
|  | 活载追踪分析 |
| ✮ | 风荷载自动计算 |
|  | 支座沉降分析 |
