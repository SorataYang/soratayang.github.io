# 13.1 **节点详细表格**

- 功能：查看已选择节点的详细表格（可编辑）。
- 命令：查询>节点详细表格。

![节点详细表格 节点详细表格 ](image/dcfc070211c4823879cd135c387c9a3_IUwYIl92dl.png "节点详细表格 节点详细表格 ")

# 13.2 **单元详细表格**

功能：查看已选择单元的详细表格（可编辑）。

命令：查询>单元详细表格。

![单元详细表格 单元详细表格 ](image/3e65f4b697524b5d6309513dd9f6941_8fTho7Fto0.png "单元详细表格 单元详细表格 ")

# 13.3 **单元重量表格**

功能：查看已选择单元的重量表格（包括材料、截面、特征尺寸整体重量），得到合计整体重量。

命令：查询>单元重量表格。

![单元重量表格 单元重量表格 ](image/46f969bdb644ba6e27dce4f403769a8_HS4cwgPteg.png "单元重量表格 单元重量表格 ")

# 13.4 **荷载统计表格**

功能：查看激活荷载的统计表格（可编辑）。

命令：查询>荷载统计表格。

![激活对话框 激活对话框 ](image/82e8f9ed62d049372a3878a31caa1f1_Wmp96DyOcm.png "激活对话框 激活对话框 ")

![荷载统计表格 荷载统计表格 ](image/43703d4d5f1248ddbf088be9751d892_19ldSyKrD4.png "荷载统计表格 荷载统计表格 ")

在空白区域右键，可重新选择激活项。
