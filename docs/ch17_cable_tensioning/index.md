# 17.1 功能介绍

该模块基于智能优化算法，以各拉索索力为设计变量，以节点位移、单元内力等为约束，建立优化模型，进行优化计算，得到理想成桥索力（或索长）。

# 17.2 基本操作

## 17.2.1 影响矩阵生成

影响矩阵界面如下：

![影响矩阵窗口操作 影响矩阵窗口操作 ](<image/图片 287_F4exSeqFZw.png> "影响矩阵窗口操作 影响矩阵窗口操作 ")

1. **调索阶段**

   选择所建立的施工阶段的数据模型：

   ![](<image/图片 288_ezk7WLhwBD.png>)
2. **张拉方式**

   与施工阶段索单元张拉方式保持一致；

   ![](<image/图片 289_akW24qsAyj.png>)
3. **张拉索工况**

   有两种生成方式，分别为快速生成和常规生成：

   快速生成方式—可以在三维视图中框选斜拉索单元，根据是否纵向对称，横向对称信息，自动生成斜拉索工况；

   ![](<image/图片 290_n9lj84caeW.png>)

   常规生成方式—需要手动生成每一个张拉索工况。也可以在张拉索工况中直接进行添加，修改，删除操作；

   ![](<image/图片 291_ozYrmb1mS6.png>)
4. **约束条件**

   节点位移Dx，Dy，Dz，Rx，Ry，Rz

   梁单元内力IJ端Fx，Fy，Fz，Mx，My，Mz

   杆系单元IJ端轴向内力

   节点号和单元号可以直接输入，也可以在三维视图中选择；
5. **生成影响矩阵**

   根据当前界面信息，调索阶段、张拉索工况、约束条件自动生成影响矩阵；
6. **查看影响矩阵**

   影响矩阵列为某个张拉索工况张拉单位力，约束条件（节点位移、单元内力）的变化值；

   ![查看影响矩阵 查看影响矩阵 ](<image/图片 292_yDq3U62OUM.png> "查看影响矩阵 查看影响矩阵 ")

## 17.2.2 设置优化初始值

![设置优化初始值界面 设置优化初始值界面 ](<image/图片 293_Ehp0Prt6ok.png> "设置优化初始值界面 设置优化初始值界面 ")

1. 张拉索工况
   - 初始值：软件可以根据模型数据自动读取张拉索工况初始值

     对于索力张拉，将自动读取截止到当前施工阶段激活荷载组中的索力张拉荷载；对于索长张拉，如果到当前激活荷载组中有索长张拉荷载，则作为张拉工况的初始值，如果没有则采用索单元初始无应力索长。
   - 上下限值：相对于初始值的变化量；
   用户可以直接在表格中进行数据修改
2. 约束条件初始值
   - 权系数：可以填1或者0，1代表考虑改约束条件，0代表不考虑改约束条件；
   - 初始值：如果有计算结果，将自动读取约束条件计算结果，作为初始值；
   - 目标值：理想目标值
   - 上下限值：约束条件优化后的上下限值；
   举例：比如节点竖向位移，目标值为0.1m，上限值为0.12m，下限值为0.08m；

   用户可以直接在表格中进行数据修改
