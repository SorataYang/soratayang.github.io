# 为什么线性计算，初次张拉斜拉索采用索长张拉，有的时候会不收敛？

线性计算的索长张拉，是通过将索长换算成索力，进行张拉计算得到真实无应力索长，与索长张拉值进行比较，不断迭代，最后得到索长张拉对应的实际索力。

当斜拉索第一次安装，由于结构自重影响，斜拉索会产生一点索力，此时的无应力索长与索长张拉值相差较大，进行迭代张拉时会出现不收敛。

所以建议线性计算，先进行索力张拉，使斜拉索有了一个比较合理的索力值之后，再进行索长张拉
