# 混凝土构件检算荷载组合中的预加力，是预应力的一次力还是一次和二次的和？

钢束的**一次力**是钢束张拉后直接作用于结构上的力，是有效应力的积分；而**二次力**是一次力产生的变形由于超静定边界条件的约束而产生的力。

\*\*公路通规4.1.5 \*\*公路桥涵结构按承载能力极限状态设计时，对持久设计状况应采用基本组合

**公路通规4.2.2** 在结构进行承载能力极限状态时，预加力不应作为作用，预应力钢筋作为结构抗力的一部分。在连续梁等超静定结构中，考虑预加力引起的次效应。

所以程序中，验算承载能力的基本组合，把一次应力的有效应力作为结构抗力的一部分考虑，而二次力会乘以系数后作为作用的一部分。但其余检算项会考虑一次力。
