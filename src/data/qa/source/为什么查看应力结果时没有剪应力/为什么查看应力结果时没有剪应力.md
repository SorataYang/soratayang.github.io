# 为什么查看应力结果时没有剪应力

梁/组合梁单元剪应力包含两项: 弯曲剪应力+扭转剪应力。

最新版本已加入该项内容，但需注意如果打开的是旧的模型，需要打开“特性→截面”，在截面列表中点击“重新计算特性”按钮，这时程序将补充计算截面静矩、等特性，之后点击运行计算，成功后将在后处理图形和表格中查看梁/组合梁单元最大剪应力结果。

本软件的构件检算模块中，可以综合考虑扭矩、剪力、和截面形状（根据截面网格）计算出更为精确的剪应力。
