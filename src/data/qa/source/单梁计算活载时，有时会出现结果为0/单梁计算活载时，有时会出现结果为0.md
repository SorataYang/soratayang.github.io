# 单梁计算活载时，有时会出现结果为0

| 问题分类  | 计算结果 |
| ----- | ---- |
| 用户提问  | True |
| 字段名 1 | 活载计算 |
| 字段名 2 |      |

单梁模型进行活载计算时，加载方式采用车轮加载，所以需要在加载位置处有影响面结果。

单梁模型进行影响面计算时，会根据节点纵列上单元的截面特性宽度参数（Cyp，Cym），进行影响面计算，如果截面宽度小于车轮加载宽度，车轮加载位置处影响面结果则为0，所以没有结果。

> 🚩解决方法：可以手动将Cyp，Cym改大一点，在车轮加载位置处就会有影响面结果

> ⚠️截面特性宽度参数（Cyp，Cym）影响
>
> 1. 预应力位置的判断：判断预应力通过哪些单元
> 2. 横向温差计算：通过宽度信息计算截面不同位置处温度
> 3. 单梁影响面计算：计算影响面横向宽度范围
