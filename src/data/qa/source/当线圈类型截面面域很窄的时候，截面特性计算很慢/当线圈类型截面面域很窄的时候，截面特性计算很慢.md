# 当线圈类型截面面域很窄的时候，截面特性计算很慢

桥通计算截面特性时，不论是普通参数类型截面还是自定义线圈截面，计算截面特性前会先划分网格，以一个18m\*0.05m的矩形截面为例，划分**四边形**网格时，网格边长默认为窄边(0.05m)/4 = 0.0125m，导致划分时在18m\*0.05m这个面域内，划分网格数量太多(18m\*0.05m)/(0.0125 \* 0.0125) = 5760个网格，导致计算截面特性时出现卡顿甚至闪退的现象，所以对于此类截面（包括钢箱梁、钢板、桁架等类型截面）, 最好是使用线宽类型的截面。
