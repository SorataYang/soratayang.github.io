# 如何理解活载工况计算结果中的合计、汽车强度、汽车车辆强度结果

| 问题分类  | 前处理界面 |
| ----- | ----- |
| 用户提问  | True  |
| 字段名 1 |       |
| 字段名 2 |       |

回答：每一个活载工况计算结果，分别会给出合计和分项结果，其中分项结果包括汽车强度、汽车车辆强度、汽车疲劳、非机动车道荷载、普通火车强度、普通火车疲劳、高速火车强度、高速火车疲劳、城市轻轨、公路疲劳荷载I、公路疲劳荷载II、公路疲劳荷载III、特载、挂车。如果在活载工况计算相应的子工况，查看结果时会输出对应的分项结果。

注意：1. 合计结果中不包含疲劳结果

&#x20;     2\. 汽车强度包括下列荷载结果：公路I级车道、公路II级车道、城A车道、城B车道、自定义车道荷载、自定义车辆荷载、汽10、汽15、汽20、汽超20

1. 汽车车辆强度包括下列荷载结果：公路I级车辆、公路II级车辆、城A车辆、城B车辆
