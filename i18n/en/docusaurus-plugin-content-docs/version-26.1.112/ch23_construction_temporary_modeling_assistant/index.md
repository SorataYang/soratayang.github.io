This chapter introduces the usage workflow of the Construction Temporary Modeling Assistant (Steel Trestle Bridge, Bailey Frame Scaffold).

The Modeling Assistant can quickly generate QiaoTong finite element models through "Parametric Input + 3D Preview", and provides commonly used cross-section/geological/load and combination settings, finally supporting verification calculations and calculation report output.
