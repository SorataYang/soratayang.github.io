QiaoTong software includes the following main modules and functions (✮ indicates featured/enhanced functions).

### Finite Element Calculation Module

| Feature | Function |
| :---: | --- |
|  | Element library: beam elements, truss elements, cable elements, shell elements |
|  | Material library: concrete, steel, prestressing, reinforcement, custom; supports orthotropic materials |
|  | Section library: general concrete, steel truss beams, steel sections, composite beams, steel box girders, variable sections |
| ✮ | Numerical and graphical bidirectional section editor |
|  | Boundaries: general supports, elastic supports, master-slave constraints, elastic links, constraint equations, beam end releases, local coordinate systems |
|  | Loads: wind, temperature, settlement, creep and shrinkage, manufacturing deviation, prestressing, etc. |
|  | General static analysis / natural vibration and buckling / response spectrum analysis |
|  | Geometric nonlinearity: full nonlinearity, partial nonlinearity |
| ✮ | Nonlinear dynamic time history analysis, nonlinear boundary elements |
|  | Load combinations: superposition, envelope, discrimination, square root of sum of squares, sum of absolute values, etc. |
|  | Post-processing: reactions, deformations, internal forces, stresses; concurrent reaction/concurrent internal force tables |
