## Version: **25.7.30.109** 

### ✨ New Features

1. Added support for **US Standards** `AASHTO-LRFDBDS-2017, 2020` and **British Standards** `BS5400-2:2006, BS5400-4:1990`, including implementation of key functions such as material properties, shrinkage and creep effects, prestress relaxation characteristics, live load application, and concrete checking as specified in these standards.
2. Added **shear stress** calculation results for beam elements and **nodal displacement** output in **local coordinates**; added graphical and tabular output for primary and secondary prestressing forces.
3. Added **effective width calculation** function for composite beam sections, supporting both parametric and custom composite sections.
4. Added functionality to modify **materials** and **cross-sections** of **beam elements and composite beam elements** during construction stages.
5. Added **steel section** types, supporting angle steel, T-sections, H-sections, etc., and introduced data from **GB/T 706-2016** and **GB/T 11263-2024** standards.

<!--truncate-->

### ⚙️ Optimizations

1. Wind load calculation module optimization: added automatic wind speed acquisition function, which can automatically extract local wind speed based on selected location.
2. Support user-specified output of **fully concurrent reactions** for **settlement load cases**, with reaction support nodes set through "Settlement Load Case - Concurrent Reaction Group".
3. Support user-specified output of **fully concurrent live load reactions**, with tracking of various live load types available through configuration at "Analysis - Live Load Settings - Result Output Options".
4. Anti-overturning combinations imported into general combinations for convenient viewing of graphical and tabular results.

### 🔧 Bug Fixes

1. Routine maintenance and resolution of known issues.
