## Version: **24.6.28.97**

### ✨ New Features

1. Concrete checking: reinforcement function upgrade, oblique section shear capacity calculation added control parameters
2. Section module: added several new channel steel, I-beam, and H-beam sections
3. Material module: customizable shrinkage and creep, different materials can be assigned different shrinkage and creep characteristics
4. Load module: added custom temperature load function
