## Version: **24.9.11.101**

### ✨ New Features

1. Wind load automatic calculation module
2. Tree menu search function
3. 3D DXF import and export
4. Right-click menu added to view load boundary tables and other information

<!--truncate-->

### ⚙️ Optimizations

1. Track geometry definition: added cubic spline interpolation fitting method, longitudinal section accounting information, and option for all longitudinal column nodes to participate in fitting
2. Buckling analysis: removed the requirement to establish construction stages
3. Construction stage cable element stress-free result table added output of tangent angles and distances at both ends

### 🔧 Bug Fixes

1. Fixed qdat import and export failures and other bugs
