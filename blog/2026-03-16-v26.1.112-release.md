## 版本号：**26.1.112**

### ✨ 新特性

1. 新增抗震检算、悬索桥抗风计算及钢箱梁检算模块；
2. 新增检算材料管理功能，支持材料检算参数自定义；
3. 新增时程分析中的双线性阻尼器、刚性阻尼器及模态阻尼支持；
4. 新增加固模块，支持加固构件材料定义；

<!--truncate-->

### ⚙️ 优化

1. 优化钢束编辑功能，支持自定义关联单元；
2. 支持单元属性（主从约束、弹性连接）的同步复制与镜像；
3. 横向车道定义支持直接指定车道数；
4. 提升截面组批量生成速度；
5. 优化横向分析荷载分布宽度计算的稳定性；
6. 优化预应力钢束特性界面的显示效果；
7. 修复 API 提取单元内力结果时速度慢的问题；
8. 优化 Python 脚本运行稳定性与交互反馈，提升参数化设计体验；

### 🔧 缺陷修复

1. 其他日常维护与已知问题修复。
