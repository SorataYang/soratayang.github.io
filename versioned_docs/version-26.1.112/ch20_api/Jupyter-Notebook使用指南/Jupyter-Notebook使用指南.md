# VS Code 中使用 Jupyter Notebook

Jupyter Notebook 是一个开源的交互式计算环境，可以将 Markdown 文档和可执行代码组合在一起。VS Code 原生支持 Jupyter Notebook，本文介绍其基本使用方法。

## 环境准备

### 安装依赖

使用 Jupyter Notebook 需要：

1. **Python 环境**：确保已安装 Python
2. **Jupyter 包**：在终端执行 `pip install jupyter`
3. **VS Code 扩展**：安装 Python 和 Jupyter 扩展

### 选择解释器

1. 按 `Ctrl+Shift+P` 打开命令面板
2. 输入 "Python: Select Interpreter"
3. 选择已安装的 Python 环境

### 工作区信任

首次打开 Notebook 时，VS Code 可能提示工作区信任设置。需要在受信任的工作区中才能执行代码单元。

## 创建和打开 Notebook

### 创建新 Notebook

**方法一**：使用命令面板
1. 按 `Ctrl+Shift+P`
2. 输入 "Create: New Jupyter Notebook"
3. 回车执行

**方法二**：直接创建文件
- 在资源管理器中创建 `.ipynb` 后缀的文件

### 选择内核

创建 Notebook 后，点击右上角的内核选择器，选择要使用的 Python 内核。

## 运行代码单元

### 基本操作

- 点击单元格左侧的 **▶ 运行按钮** 执行代码
- 输出结果显示在单元格下方

### 常用快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Enter` | 运行当前单元格 |
| `Shift+Enter` | 运行当前单元格并跳转到下一个 |
| `Alt+Enter` | 运行当前单元格并在下方插入新单元格 |

### 批量运行

点击工具栏按钮可批量运行：
- **Run All**：运行所有单元格
- **Run All Above**：运行当前单元格上方的所有单元格
- **Run All Below**：运行当前单元格下方的所有单元格

## 单元格操作

### 单元格模式

单元格有两种主要模式：

| 模式 | 特征 | 进入方式 |
|------|------|----------|
| **命令模式** | 左侧蓝色竖条，可执行快捷键命令 | 按 `Esc` |
| **编辑模式** | 左侧绿色竖条，可编辑内容 | 按 `Enter` 或点击单元格 |

### 添加单元格

- 点击单元格之间的 **+** 按钮
- 命令模式下按 `A` 在上方添加
- 命令模式下按 `B` 在下方添加

### 移动单元格

- 拖拽单元格左侧区域调整顺序
- 使用 `Alt+↑` 或 `Alt+↓` 快捷键

### 删除单元格

- 点击单元格工具栏的删除图标
- 命令模式下按 `dd`（连按两次 d）

### 切换单元格类型

命令模式下：
- 按 `M` 切换为 Markdown 单元格
- 按 `Y` 切换为代码单元格

## 变量浏览器

1. 运行包含变量的代码单元格
2. 点击工具栏的"变量"图标
3. 在底部面板查看当前会话中的所有变量
4. 双击变量可在数据查看器中查看详细内容

## 保存和导出

### 保存

使用 `Ctrl+S` 保存 Notebook。

### 导出格式

点击工具栏的导出按钮，支持导出为：

| 格式 | 说明 |
|------|------|
| Python (.py) | 将所有代码单元格导出为 Python 脚本 |
| HTML | 导出为网页格式，保留输出结果 |
| PDF | 需要安装 TeX，导出为 PDF 文档 |

## 调试

### 逐行运行

1. 点击单元格工具栏的 "Run by Line" 按钮
2. 使用同一按钮逐行执行
3. 点击 "Stop" 按钮停止，或 "Continue" 继续执行到单元格末尾

### 完整调试

1. 在代码行左侧点击设置断点（红点）
2. 点击单元格菜单中的 "Debug Cell"
3. 使用调试工具栏（继续、单步跳过、单步进入等）控制执行
4. 在调试控制台查看变量值

## 搜索

1. 按 `Ctrl+F` 打开搜索框
2. 输入搜索内容
3. 点击漏斗图标可筛选搜索范围：
   - Markdown 源码
   - 渲染后的 Markdown
   - 代码单元格输入
   - 代码单元格输出
